# Countries API

O projeto foi desenvolvido com o objetivo de praticar consumo de APIs, requisições HTTP, manipulação de respostas JSON, variáveis de ambiente e organização de aplicações Python.

## Funcionalidades

- Consultar o número total de países disponíveis
- Consultar a população de um país
- Consultar as moedas utilizadas por um país
- Suporte a nomes de países compostos
- Autenticação via API Key
- Tratamento de erros de requisição
